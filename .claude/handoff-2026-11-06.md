## How the prize works (non-obvious parts)
- A game code is `GAME-` + 8 characters. The prefix is what makes a code single-use and time-limited; every other code (e.g. `WELCOME10`) behaves as before.
- The shop admin (tissu-agent) is the single source of truth. The site creates the code there through the existing `POST /api/promo-codes` and never returns it to the browser: it is only emailed (Resend, same key and sender as order emails).
- The admin "აღწერა" column reads `თამაში · <email> · ვადა <dd.mm.yyyy>`. That text is also how "one code per email, ever" is enforced, so do not change the format without updating `gameCodeEmail()`.
- Valid through the end of the 7th day, Tbilisi time. The admin list keeps showing an expired code as "აქტიური"; the site refuses it by date.
- Used on the site: checkout switches the code off and appends `გამოყენებულია საიტზე (შეკვეთა N)`. Used in chat: the owner presses "გათიშე" herself in the admin's პრომოკოდები tab.
- Checkout never refuses an order over a promo code (payment is agreed later by hand). A code that should not have worked gets a ⚠ line in the order notes instead.
- Abuse limits live in server memory (reset on redeploy): 5 prize requests per hour per visitor, 300 prize emails per day in total, 20 code checks per 10 minutes per visitor.
